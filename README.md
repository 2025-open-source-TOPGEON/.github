# TOPGEON - Synthor

## 🚀 프로젝트 개요
**Synthor**는 개발자를 위한 **AI 기반 더미 데이터 생성 플랫폼**입니다.  
복잡한 조건이나 다양한 데이터 타입을 손쉽게 생성하고, 원하는 포맷(JSON, CSV, SQL 등)으로 바로 변환할 수 있어  
테스트 및 개발 효율성을 극대화합니다.  

본 프로젝트는 **2025 오픈소스 공모전 출품작**으로,  
Frontend · Backend · AI 모듈이 유기적으로 협력하는 통합 시스템입니다.

---

## ✨ 주요 기능
- **데이터 타입 다양성**  
  9개 카테고리, 총 **51종의 데이터 타입** 지원  
  (이름, 이메일, 비밀번호, 전화번호, 주소, 날짜/시간, 회사/제품, 색상/언어 등)  
- **AI 조건 생성**  
  자연어 프롬프트로 *“김씨 성만”*, *“네이버 메일만”*, *“특수문자 포함 비밀번호”* 와 같은 조건 기반 데이터 생성  
- **다양한 포맷 변환 (6종)**  
  - JSON  
  - CSV  
  - SQL  
  - HTML  
  - XML  
  - LDIF  
- **웹 UI 제공**  
  직관적이고 사용자 친화적인 React 기반 인터페이스  
- **REST API 제공**  
  Swagger 기반 문서화, 손쉬운 외부 연동 가능  

---

## 🏗️ 시스템 구조
- **[Synthor-front](./Synthor-front)** – React 기반 사용자 인터페이스  
- **[Synthor-back](./Synthor-back)** – Spring Boot 기반 API 서버 & 데이터 변환  
- **[Synthor-AI](./Synthor-AI)** – Python 기반 AI 데이터 생성 모듈  
- **[Synthor-templates](./Synthor-templates)** – 예시 데이터 및 템플릿 관리  

---

## 👥 팀 TOPGEON
- **Frontend**: UI/UX 및 사용자 경험 설계  
- **Backend**: 서버, 데이터 처리 및 API 관리  
- **AI**: 조건 기반 데이터 생성 및 최적화  

---

## 🎯 프로젝트 의의
테스트 데이터 생성은 반복적이고 번거로운 작업이지만, **Synthor**는 이를 자동화하여  
개발 생산성을 높이고, 다양한 환경에서 활용 가능한 데이터 활용성을 제공합니다.
